# Swipe24

A responsive landing page for Swipe24, built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://swipe24.netlify.app/

## 📌 About the Project

Swipe24 is a modern, responsive landing page designed to showcase a digital payments and financial technology platform.

The website includes:

- Responsive navigation
- Hero section with mobile app preview
- Partner/company logos
- Unified platform section
- Integration/API section
- Product feature cards
- Global payments section
- Virtual events section
- Getting started section
- Responsive footer
- Animated gradient background

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG and PNG assets
- Netlify
- GitHub
